You are a Senior Product Designer from Linear / Stripe / Vercel.

Your task is NOT to redesign the application flow.

Your task is ONLY to improve the visual design while preserving the existing wireframe, layout, information architecture, and functionality.

## Absolute Constraints

DO NOT:
- move major sections
- change navigation position
- change dashboard layout
- add unnecessary components
- remove existing features
- redesign user flow
- create a Dribbble concept

Keep exactly the same:
- sidebar
- top navbar
- map section
- graph section
- warning panel
- metrics panel
- search
- dropdowns
- cards
- overall responsive layout

Think of this as a visual refinement instead of a redesign.

------------------------------------------------

Current problem

The UI feels:
- too rigid
- too flat
- too "AI-generated dashboard"
- visually heavy
- lacks elegance
- lacks hierarchy
- everything has equal visual weight
- borders are overused
- insufficient whitespace
- typography lacks rhythm
- interactions feel static

The UI is already functional.

Do NOT solve usability.

Solve aesthetics.

------------------------------------------------

Design Direction

Target aesthetic:

- Linear
- Vercel
- Stripe Dashboard
- Arc Browser
- Raycast
- Notion Calendar
- Apple Human Interface
- modern SaaS dashboard

Keywords

clean
minimal
calm
refined
professional
premium
soft
airy
editorial
high-end enterprise

NOT

glassmorphism
neumorphism
cyberpunk
futuristic
colorful
dribbble style
overdesigned

------------------------------------------------

Visual Hierarchy

Create a much stronger hierarchy.

Users should instantly understand:

1. Map is the primary content.
2. Analytics is secondary.
3. Metrics support decisions.
4. Warning cards are informative.
5. Navigation stays visually quiet.

------------------------------------------------

Borders

Reduce borders dramatically.

Instead of outlining everything:

use

- spacing
- subtle background differences
- elevation
- light shadows

Only keep borders where they truly improve separation.

------------------------------------------------

Depth

Introduce subtle depth.

Use

- soft shadows
- layered surfaces
- gentle elevation

Avoid obvious floating cards.

The dashboard should feel premium, not dramatic.

------------------------------------------------

Spacing

Increase whitespace by around 20–30%.

Give breathing room between:

- cards
- panels
- metrics
- graphs
- controls

Nothing should feel cramped.

------------------------------------------------

Typography

Improve typography hierarchy.

Differentiate clearly between:

- page title
- section title
- card title
- labels
- values
- helper text

Use font weight and size intentionally.

Avoid making everything visually equal.

------------------------------------------------

Cards

Cards should feel lighter.

Reduce visual noise.

Avoid thick outlines.

Use cleaner padding and more balanced proportions.

------------------------------------------------

Radius

Use consistent modern corner radius.

Prefer:

12px–16px

instead of small sharp corners.

------------------------------------------------

Color

Keep the existing color palette.

Do NOT introduce many new colors.

Instead:

- improve neutral tones
- improve contrast
- improve accent usage

Accent color should guide attention, not decorate.

------------------------------------------------

Sidebar

Keep the sidebar exactly where it is.

Make it visually lighter.

Reduce unnecessary visual weight.

Hover and active states should feel smooth and modern.

------------------------------------------------

Navigation

Top navigation should feel calm.

Reduce visual competition between:

- buttons
- dropdowns
- search

Primary actions should stand out naturally.

------------------------------------------------

Charts

Do not redesign the charts.

Only improve:

- spacing
- labels
- typography
- grid subtlety
- card presentation

------------------------------------------------

Map

The map is the hero component.

Give it stronger visual presence using:

- subtle elevation
- better framing
- cleaner controls
- improved whitespace

Without changing its position or size.

------------------------------------------------

Micro Interactions

Add subtle interactions.

Examples:

- 180–250ms transitions
- hover elevation
- soft hover backgrounds
- active states
- smooth dropdown animations
- focus rings
- refined button feedback

Animations should feel almost invisible.

------------------------------------------------

Consistency

Everything should follow an 8px spacing system.

Maintain consistent:

- radius
- shadows
- spacing
- typography
- icon sizes
- alignment

------------------------------------------------

Final Goal

When someone sees this dashboard, they should think:

"This feels like a polished enterprise SaaS product designed by an experienced product design team."

NOT

"This looks AI generated."

The redesign should be subtle enough that users recognize the original interface immediately, but refined enough that it feels significantly more modern, lighter, smoother, and premium.
